# Install QuotaBar

Clone this repository on macOS 14+, then run `bash install.sh`. This builds the checked-out source and installs QuotaBar to `/Applications` (or `~/Applications` when needed).

Requires Swift 6+ through Xcode or Command Line Tools. No sudo, downloaded installer, credential entry, or changes to the existing LimitBar app are involved. See README.md for usage sources and optional Claude status-line integration.
